# Jars Finance for Android

A local budgeting app with jars, purchases, recurring costs and monthly history.

[Download the latest APK](https://github.com/GlennBakkah/Jar-Finance-Releases/releases/latest/download/Jar-Finance.apk)

Requires Android 8 or later. This is an early debug build distributed directly as an APK.

## Install and update

Open the APK on your phone and approve installation. Install over your existing Jars app to retain its data; do not uninstall first. From version 0.1.2, Settings → Check for updates checks this repository. Downloads and installation require your confirmation. Version 0.1.1 users must install 0.1.2 manually once to switch to this update source.

Your budget remains on your device. Update checks contact GitHub only on request and do not upload financial data. Use the app's Export backup option to keep a separate recovery copy.

This repository contains APK releases and download instructions. Application source is maintained separately. APKs are signed with the original app certificate; the app verifies the certificate before offering an update.
